# Landscape Mapping

## Overview

GIS project created in QGIS using OpenStreetMap data as a spatial
reference and basemap.

The project focuses on the identification, manual digitization
and visualization of landscape features, including natural areas,
roads, trails, buildings and waterways.

## Data

- OpenStreetMap (OSM)
- OpenStreetMap basemap
- Manually digitized vector features

## Methods

- Visual interpretation of spatial data
- Manual digitization of landscape features
- Vector layer creation and editing
- Cartographic visualization

## Software

- QGIS
- OpenStreetMap
